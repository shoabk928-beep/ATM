# ATM Banking System

A professional and responsive ATM Banking System built using HTML, CSS, and JavaScript. The project provides a clean banking interface with secure PIN authentication and basic account transaction functionality.

## Features

* Secure 4-digit PIN authentication
* Account balance display
* Cash withdrawal
* Money deposit
* Transaction history
* Logout functionality
* Responsive design
* Professional banking dashboard
* Client-side validation
* Clean and modern user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using a browser or Live Server.
4. Enter the demo PIN `1234`.
5. Test the ATM features.

## ATM Operations

### Check Balance

Displays the current available account balance.

### Withdraw Cash

Allows the user to withdraw money when sufficient balance is available.

### Deposit Money

Allows the user to add money to the account.

### Transaction History

Displays recent deposits and withdrawals with date and time.

### Logout

Ends the current ATM session and returns to the login screen.
